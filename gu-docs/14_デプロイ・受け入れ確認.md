## 用意した配布・デプロイ処理

- `scripts/package_release.py`：BackendとNext.js standaloneのZIPを作成し、ZIPの整合性と環境ファイルの除外を確認します。`.release/manifest.json` にSHA-256とサイズを記録します。`.release/` はGit対象外です。
- `scripts/deploy_azure.py`：省略時は計画だけ表示。`--apply` で指定したテスト用Web Appへ設定・配布し、`--create` の場合だけ未作成リソースをFree F1で作ります。共有DBは作成・更新・初期化しません。
- `--configure-only` はMacからAzureとGitHubの設定だけを行う用途です。Linux以外からのFrontend ZIPデプロイは拒否し、実際の配布はLinuxのGitHub Actionsでビルドします。
- `--configure-github` はPublish Profile、JOB_SECRET、BACKEND_URL、Stripe公開キーをGitHub Actions Secretsへ、アプリ名とDEPLOYMENT_ENABLEDをVariablesへ設定します。configure-onlyでは定期実行をfalseのままにし、デプロイ後の動作確認が済んでからtrueにします。秘密値は標準出力へ出さず、Azureへ渡す一時設定ファイルは0600で作成して削除します。
- `.github/workflows/deploy-backend.yml`・`deploy-frontend.yml`：mainのCIが成功した同じコミット、または手動実行をデプロイ。未設定のアプリ名では実行しません。Frontendは本物のpk_test_公開キーを要求します。
- `.github/workflows/jobs.yml`：10分ごとにJ-01〜05、毎日UTC18時＝日本時間3時にJ-06・07。DEPLOYMENT_ENABLED=trueにした後に動きます。

インフラ設計の「main push」を、そのpushに対するCI成功後の `workflow_run` として実装しました。検査が失敗したコミットを自動デプロイしないためです。任意のforkのワークフローからはデプロイしません。

## 計画の確認と実行

プロジェクト直下から実行します。次の最初のコマンドは外部を変更しません。

```sh
backend/.venv/bin/python scripts/deploy_azure.py --create --configure-github --configure-only
```

既定の作成候補は `rg-pickup-app-shiochi`、Free F1プラン `plan-pickup-shiochi`、Web Apps `app-pickup-front-shiochi`／`app-pickup-back-shiochi`、Japan Eastです。既存環境をまだ一覧取得できていないため確定した公開先ではありません。既存の所有リソースや名前の利用可否を確認して、必要なら引数で変更します。有料プランへの自動切り替えはしません。

再認証・Stripe設定と実行対象の確認ができた後の設定コマンドは次の形です。

```sh
backend/.venv/bin/python scripts/deploy_azure.py --apply --create --configure-github --configure-only
```

その後、承認済みのソースを公開リポジトリへpushし、CIとLinuxでのデプロイを確認します。healthzと注文・受取の動作確認後に `gh variable set DEPLOYMENT_ENABLED --repo shiochisss/gu-app --body true` で定期実行を有効にします。既存Azure DBはStep2の全テーブルを持つ前提で、今回新しいマイグレーションはありません。起動時にマイグレーション・seed・resetを実行しません。DB変更が別途必要と判明した場合は対象と差分を確認します。

配布物をローカルで作成するには次を実行します。

```sh
cd frontend
npm run build
cd ..
backend/.venv/bin/python scripts/package_release.py all
```

このMacで作ったFrontend ZIPは配布構成の確認用です。AzureへはGitHub ActionsがLinuxで作り直したZIPを使用します。公開キーはビルド時に埋め込まれます。
